# ربات تلگرام قیمت لحظه‌ای ارز دیجیتال

این پروژه یک ربات تلگرامی است که قیمت لحظه‌ای ارزهای دیجیتال را با استفاده از API عمومی CoinGecko نمایش می‌دهد.

## قابلیت‌ها
- دریافت قیمت لحظه‌ای با دستور `/price <symbol>` (مثال: `/price btc`)
- میانبر برای ارزهای محبوب: `/btc`، `/eth`، `/bnb`، `/sol`، `/xrp`، `/ada`، `/doge`، `/ton`، `/trx`، `/ltc`
- نمایش تغییر ۲۴ ساعته
- **نمایش قیمت‌ها به ریال ایران** 🇮🇷
- واچ‌لیست شخصی و مدیریت پرتفوی
- هشدارهای قیمت
- اخبار ارزهای دیجیتال
- تحلیل تکنیکال (RSI, MACD, SMA)
- مقایسه قیمت بین صرافی‌ها
- نرخ‌های P2P بایننس

## پیش‌نیازها
- Python 3.10 یا بالاتر
- یک توکن ربات تلگرام (از BotFather دریافت کنید)

## راه‌اندازی (Windows PowerShell)
1. مخزن/پروژه را دانلود یا کلون کنید و سپس وارد پوشه پروژه شوید.
2. یک فایل `.env` بسازید و مقدار توکن را قرار دهید:

```
TELEGRAM_BOT_TOKEN=توکن_ربات_شما
```

یا از فایل نمونه `.env.example` کپی بگیرید و مقدار را جایگزین کنید.

3. نصب وابستگی‌ها:

```
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

4. اجرای ربات:

```
python main.py
```

پس از اجرای موفق، در تلگرام به ربات پیام دهید:
- `/start` یا `/help`
- `/price btc`
- یا از میانبرها مثلا `/eth`

## تنظیمات نمایش ریال ایران 🇮🇷

برای فعال/غیرفعال کردن نمایش قیمت‌ها به ریال ایران:
1. دکمه **🛠 تنظیمات** را انتخاب کنید
2. روی **نمایش ریال ایران** کلیک کنید تا وضعیت آن تغییر کند
3. حالا قیمت‌ها هم به ریال ایران نمایش داده می‌شوند

مثال خروجی:
```
قیمت لحظه‌ای BTC:
💵 45,000.0000 دلار
🇮🇷 22,500,000 تومان
تغییر ۲۴ساعته: +2.50% 📈
```

## نکات
- منبع قیمت CoinGecko است و نیازی به API Key ندارد.
- در صورت نیاز می‌توانید نگاشت نماد به شناسه CoinGecko را در فایل `price_service.py` بخش `SYMBOL_TO_CG_ID` گسترش دهید.
- در صورت بروز خطاهای موقتی شبکه، دوباره تلاش کنید.
