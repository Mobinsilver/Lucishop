# Crypto Navasan Bot

A comprehensive Telegram bot for crypto and fiat currency tracking.

## Features

- Real-time crypto price tracking
- Fiat currency rates
- News feed integration
- Technical analysis
- P2P trading data
- Portfolio management
- Watchlist functionality
- Price alerts
- Multi-language support
- Admin panel

## Railway Deployment

Ready for Railway deployment!

### Environment Variables:
- BOT_TOKEN
- OWNER_ID  
- BOT_USERNAME

### Start Command:
python main.py

## Usage

Start with /start command and use menu buttons.
