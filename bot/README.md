# 🤖 ربات تلگرام کریپتو یار (Crypto Yar Bot)

ربات هوشمند قیمت لحظه‌ای ارزهای دیجیتال و فیات با قابلیت‌های پیشرفته

## ✨ ویژگی‌ها

### 💰 **قیمت ارزهای دیجیتال**
- قیمت لحظه‌ای از CoinGecko و Binance
- نمایش تغییرات ۲۴ ساعته
- پشتیبانی از ارزهای اصلی: BTC, ETH, BNB, SOL, XRP, ADA, DOGE, TON, TRX, LTC
- تبدیل خودکار به ریال/تومان

### 💱 **نرخ ارزهای فیات**
- نرخ لحظه‌ای ارزهای جهانی
- پشتیبانی از EUR, GBP, JPY, CNY, AED, TRY, CAD, AUD و...
- تبدیل خودکار به ریال ایران

### 📰 **اخبار کریپتو**
- اخبار لحظه‌ای از منابع معتبر
- فیلتر بر اساس نماد ارز
- لینک مستقیم به مقالات

### 📊 **نمودار و تحلیل**
- نمودار sparkline ۷ روزه
- تحلیل تکنیکال (RSI, MACD, SMA)
- سطوح حمایت و مقاومت

### ⚖️ **مقایسه قیمت**
- مقایسه قیمت بین CoinGecko و Binance
- محاسبه اختلاف درصدی
- شناسایی فرصت‌های آربیتراژ

### 🔄 **P2P Binance**
- قیمت‌های P2P Binance
- پشتیبانی از USDT, BNB, BTC
- نمایش حداقل و حداکثر معاملات

### 👁 **واچ‌لیست شخصی**
- اضافه/حذف ارزهای مورد نظر
- مدیریت آسان

### 📚 **پرتفوی شخصی**
- ثبت خریدهای ارز
- محاسبه ارزش فعلی
- نمایش سود/زیان

### 🔔 **هشدارهای قیمت**
- تنظیم هشدار برای سطوح مختلف
- اعلان خودکار

### 🛠 **تنظیمات شخصی**
- انتخاب زبان (فارسی، انگلیسی، عربی)
- تغییر ارز پایه
- تنظیم نمایش ریال/تومان

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- Python 3.11+
- Telegram Bot Token
- دسترسی به اینترنت

### نصب محلی
```bash
# کلون کردن پروژه
git clone <repository-url>
cd bot

# نصب وابستگی‌ها
pip install -r requirements.txt

# تنظیم متغیرهای محیطی
cp .env.example .env
# ویرایش .env و اضافه کردن BOT_TOKEN

# اجرای ربات
python main.py
```

### راه‌اندازی روی Railway
1. Push پروژه به GitHub
2. ایجاد پروژه جدید در Railway
3. اتصال به GitHub repository
4. تنظیم متغیرهای محیطی
5. Deploy

## 📁 ساختار پروژه

```
bot/
├── main.py                    # فایل اصلی ربات
├── config.py                  # تنظیمات مرکزی
├── store.py                   # مدیریت داده‌ها
├── security.py                # امنیت و محدودیت‌ها
├── cache.py                   # سیستم کش
├── price_service.py           # سرویس قیمت ارز
├── fiat_service.py            # سرویس نرخ ارز
├── news_service.py            # سرویس اخبار
├── history.py                 # تاریخچه قیمت
├── arbitrage.py               # مقایسه قیمت
├── p2p_service.py             # سرویس P2P
├── ta.py                      # تحلیل تکنیکال
├── requirements.txt            # وابستگی‌های Python
├── Procfile                   # تعریف Railway
├── railway.json               # تنظیمات Railway
├── Dockerfile                 # کانتینر Docker
├── .env.example               # نمونه متغیرهای محیطی
└── README-RAILWAY.md          # راهنمای Railway
```

## 🔧 تنظیمات

### متغیرهای محیطی
```bash
TELEGRAM_BOT_TOKEN=your_bot_token_here
OWNER_ID=your_owner_id
ADMIN_ID=your_admin_id
BOT_USERNAME=your_bot_username
WEBHOOK_URL=https://your-domain.railway.app/webhook
PORT=8000
```

### تنظیمات پیش‌فرض
- زبان: فارسی
- ارز پایه: USD
- نمایش ریال: فعال
- نمایش تومان: فعال
- محدودیت درخواست: ۱۲ درخواست در ۱۰ ثانیه

## 📱 دستورات ربات

### دستورات اصلی
- `/start` - شروع ربات
- `/help` - راهنما
- `/price <symbol>` - قیمت ارز (مثل: /price btc)

### دستورات میانبر
- `/btc`, `/eth`, `/bnb`, `/sol` - قیمت مستقیم ارز
