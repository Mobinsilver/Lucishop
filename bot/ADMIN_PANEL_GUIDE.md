# 🔐 راهنمای پنل مدیریتی پیشرفته

## 🎯 دسترسی به پنل مدیریتی

### روش‌های دسترسی:
1. **دستور مستقیم**: `/admin`
2. **دکمه کیبورد**: 🔐 پنل مدیریتی (فقط برای مالک)

### محدودیت دسترسی:
- ✅ فقط مالک ربات (OWNER_ID) می‌تواند به پنل دسترسی داشته باشد
- ❌ ادمین‌ها دسترسی به پنل مدیریتی ندارند

---

## 📋 بخش‌های پنل مدیریتی

### 1. 👥 مدیریت ادمین‌ها
**قابلیت‌ها**:
- ➕ افزودن ادمین جدید
- ➖ حذف ادمین
- 📋 مشاهده لیست ادمین‌ها

**نحوه استفاده**:
1. روی "مدیریت ادمین‌ها" کلیک کنید
2. "افزودن ادمین" را انتخاب کنید
3. آیدی عددی کاربر را ارسال کنید
4. ادمین با موفقیت اضافه می‌شود

### 2. 📢 ارسال همگانی
**قابلیت‌ها**:
- 📢 ارسال به همه کاربران
- 👥 ارسال به ادمین‌ها
- ⚪ ارسال به لیست سفید

**نحوه استفاده**:
1. روی "ارسال همگانی" کلیک کنید
2. نوع ارسال را انتخاب کنید
3. پیام خود را ارسال کنید (متن، عکس، ویدیو، فایل)
4. نتایج ارسال نمایش داده می‌شود

**نکات مهم**:
- از Markdown پشتیبانی می‌شود
- می‌توانید عکس، ویدیو یا فایل ارسال کنید
- برای جلوگیری از محدودیت، بین ارسال‌ها تاخیر وجود دارد

### 3. 📝 تنظیم متن‌ها
**قابلیت‌ها**:
- 👋 متن خوش‌آمدگویی (/start)
- ❓ متن راهنما (/help)
- ⚠️ متن خطاها
- 📝 متن درباره ربات

**متغیرهای قابل استفاده**:
- `{name}` - نام کاربر
- `{username}` - نام کاربری
- `{user_id}` - آیدی کاربر

### 4. 🔧 تنظیمات API
**قابلیت‌ها**:
- 🔑 تنظیم API Key جدید
- 🔄 تغییر Provider
- 📊 بررسی وضعیت API

**Provider های فعلی**:
- 💰 ارز دیجیتال: CoinGecko
- 💱 ارز فیات: ExchangeRate.host

### 5. 🔒 قفل اجباری
**قابلیت‌ها**:
- ✅/❌ فعال/غیرفعال کردن قفل اجباری
- 📢 تنظیم کانال اجباری

**نحوه کار**:
- کاربران باید عضو کانال مشخص شده باشند
- در غیر این صورت دسترسی محدود می‌شود

### 6. ⚪ لیست سفید/سیاه
**قابلیت‌ها**:
- ➕ افزودن کاربر به لیست سفید
- ➖ حذف کاربر از لیست سفید
- ⚫ افزودن کاربر به لیست سیاه
- ⚪ حذف کاربر از لیست سیاه
- 📋 مشاهده لیست کامل

### 7. 📊 آمار و گزارش
**قابلیت‌ها**:
- 📊 گزارش کامل
- 📈 نمودار کاربران
- 🔄 بروزرسانی آمار

**آمار نمایش داده شده**:
- کل کاربران
- کاربران فعال (۷ روز)
- ادمین‌ها
- لیست سفید/سیاه
- نرخ رشد

### 8. 🗄️ مدیریت کش
**قابلیت‌ها**:
- 🗑️ پاک کردن کش
- 📊 اطلاعات کش
- 🔄 بروزرسانی کش

**فواید**:
- بهبود سرعت ربات
- آزادسازی حافظه
- بروزرسانی داده‌ها

### 9. ⚙️ تنظیمات سیستم
**قابلیت‌ها**:
- ⚡ تنظیمات عملکرد
- 🔒 تنظیمات امنیتی
- 📝 تنظیمات لاگ
- 🔄 تنظیمات بروزرسانی

### 10. 💾 پشتیبان‌گیری
**قابلیت‌ها**:
- 💾 ایجاد پشتیبان
- 📥 بازگردانی
- 📋 لیست پشتیبان‌ها

**هشدار**: بازگردانی تمام داده‌های فعلی را جایگزین می‌کند!

### 11. 📋 لاگ‌ها
**قابلیت‌ها**:
- 📋 لاگ‌های امروز
- 📊 لاگ‌های هفته
- 🔍 جستجو در لاگ
- 🗑️ پاک کردن لاگ

### 12. 🔔 مدیریت هشدارها
**قابلیت‌ها**:
- 📊 آمار هشدارها
- ⚙️ تنظیمات هشدار
- 🔔 تست هشدار

### 13. ⌨️ دستورات سفارشی
**قابلیت‌ها**:
- ➕ افزودن دستور جدید
- 📋 لیست دستورات
- ✏️ ویرایش دستور
- 🗑️ حذف دستور

### 14. 🤖 تنظیمات ربات
**قابلیت‌ها**:
- 🤖 اطلاعات ربات
- ⚙️ تنظیمات عمومی
- 🎨 تنظیمات ظاهری
- 🔧 تنظیمات فنی

---

## 🛠️ دستورات مفید

### دستورات پنل:
- `/admin` - باز کردن پنل مدیریتی
- `/cancel` - لغو عملیات فعلی

### کلیدهای میانبر:
- 🔙 بازگشت - بازگشت به منوی قبلی
- ❌ خروج - خروج از پنل مدیریتی

---

## 🔒 امنیت

### محدودیت‌های امنیتی:
- فقط مالک ربات دسترسی دارد
- تمام عملیات لاگ می‌شوند
- تغییرات مهم نیاز به تایید دارند

### نکات امنیتی:
- آیدی مالک در `config.py` تنظیم شده
- تغییرات در `store.json` ذخیره می‌شوند
- پشتیبان‌گیری منظم توصیه می‌شود

## 📞 پشتیبانی

### در صورت مشکل:

2. پشتیبان تهیه کنید
3. تنظیمات را ریست کنید
4. با توسعه‌دهنده تماس بگیرید
